# 🍽️ DharshiniDelights – Online Food Ordering Website

## 📌 About the Project
DharshiniDelights is an online food ordering website that allows users to explore food items, view menus, add items to their cart and place orders through a simple interface.

## ✨ Features
- Attractive home page
- Food menu with images and prices
- Add to cart functionality
- Cart management
- Order placement
- Order success page
- Contact and About pages

## 💻 Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Pages
- Home
- Menu
- Cart
- About
- Contact
- Order Success

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website.
